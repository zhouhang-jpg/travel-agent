# 出行助手 Web

React、TypeScript、Vite 的中文对话界面。完整会话保存在后端；浏览器只记住当前会话 ID，用于刷新后恢复。

## 本地运行

先在仓库根目录启动后端（`127.0.0.1:8000`），再在本目录执行：

```powershell
pnpm install
pnpm dev
```

Vite 把 `/api/*` 代理到后端 `/*`。模型和数据服务的密钥只放在后端配置，前端不接收或存储密钥。

```powershell
pnpm test
pnpm build
```

生产部署时需要由同源反向代理提供 `/api`，并支持 SSE、不缓冲响应。`pnpm preview` 仅用于本地预览构建产物。

## 对话行为

- 新建或切换会话，发送自然语言需求，继续回答助手的追问。
- 执行时禁用当前会话的输入和发送；没有停止按钮，可以切换会话。
- POST 消息以 SSE 接收状态、工具动作和助手消息；原始工具参数、结果和模型推理不进入展示层。
- SSE 结束后用后端的完整 transcript 替换临时消息；刷新、切回或连接中断时，持续每 2 秒查询运行中的会话，直到结束。
- Markdown 禁止 HTML 和图片，仅允许 HTTP/HTTPS 来源链接。
- 检测到模型未配置时提示配置后端 DeepSeek API Key。HTTP 错误按普通错误读取，不当作 SSE。

测试覆盖 SSE 的跨块帧边界、CRLF、多行数据、UTF-8 中文拆分和无效 JSON。界面联调需要实际启动后端。
