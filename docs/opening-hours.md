# 景点开放时间查询

`get_attraction_opening_hours` 为 LLM 获取开放时间证据，何时调用仍由模型根据任务决定。
它不是预订或预约工具，也不要求所有行程、所有景点都查询一次。

## 输入和地点身份

必填 `attraction_name`，可提供 `city`、已解析的高德 `place_id`、计划当地日期
`visit_date` 和已找到的景区/场馆网页 `official_urls`。日期尚未确定时仍可查常规规则。
网页 URL 是建议来源，不因为参数名为 official 就自动认证为官网；URL 凭据禁止，读取沿用
公开网页工具的公网 DNS、连接固定、重定向和内容安全边界。

有 POI ID 时读取高德详情；否则按名称和城市查询最多五个候选，只选择返回候选中唯一的
规范化名称匹配。括号和空格可等价，不做模糊首条匹配。同名或不同分馆返回 ambiguous，
不把不同候选的规则拼成同一场馆。单次查询并非穷尽全国同名地点，仍需模型核对地址/分馆。
指定 ID 的实际名称与请求不同会保留实际身份并警告。

## 证据和日期边界

- `map_reference.today_raw/week_raw` 保留高德原文；`queried_local_date` 仅为查询日期。
  高德未提供数据更新时间时保持 null，today 描述不能直接用于未来参观日期。
- 网页分别进行常规规则和计划日期公告定向搜索，保留搜索摘要、原文发布时间与来源。
  已建议官网时将其域名加入查询关键词作为搜索提示；这不是供应商保证执行的域名过滤。
- 网页读取优先调用方建议页面，再从日期公告和常规规则各选候选，最多读取三页。
  建议域名匹配、政府域名和官方字样仅影响排序，不证明站点身份或内容适用于该分馆。
- 每份原文保留来源 URL、最终 URL、查询时间、可空的数据时间、用途和显式截断状态。
  不把查询时间当作发布日，不把搜索日期当作公告适用日。
- `date_specific_status=unconfirmed`、`source_conflicts=not_evaluated` 是工具的事实边界。
  此版负责证据检索，不自动把任意网页文本解析为可靠的日历，也不自动选择冲突来源。
  LLM 需基于原文核实官方身份、有效期、分馆、每周闭馆、停止售票/入园、假日及临时变化。
  可以说明常规规则在某日的推断，不能声称已得到当天确认；没有公告不代表当天开放。

`attempts` 分开记录成功、未配置和失败。子查询最多八秒；检索和读取各一阶段，总体仍受
工具调度时限控制。某个来源失败不会抹掉其他成功证据；全部来源未配置/失败则明确报错，
而成功搜索的空结果保持“未找到”，不能当成开放。无需增加新密钥，复用高德、博查和网页读取。
只有公开网页时可传已知页面；无任何可查来源时不会返回伪成功。

## 验证和复现

离线测试覆盖同名/分馆、模糊结果、缺字段、日期隔离、冲突原文保留、来源失败与超时、
网页跳转身份、未配置和私网 URL 阻止；通过 registry 和 API 导出新工具契约。

```powershell
uv run pytest -q tests/test_opening_hours.py
uv run python scripts/live_probe_opening_hours.py --live
```

2026-10-09 实测上海博物馆人民广场馆：高德返回 POI `B001535BBC` 的营业描述，博查返回
常规及日期搜索结果，网页工具读到[官网参观页](https://www.shanghaimuseum.cn/mu/frontend/pg/m/service/visit-west)。
该页面含常规开放 9:00–17:00、15:00 停止入场、周一闭馆（国定节假日例外），还明确夜场调整需
查看官方发布。探针把计划日期设为 2026-10-12；日期搜索中存在旧公告，不能据搜索命中确认当天。
一次公告网页读取超时，其他证据仍成功保留；官网原文未截断。

此结果证明该样例在查询时能读取这些来源，不证明全国景点、任意未来日期或预约库存全覆盖。
JS、登录、PDF、验证码及网页读取本身不支持的页面仍可能缺失，缺失需保留未知。
