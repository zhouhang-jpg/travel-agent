# 票务与酒店供应商接入状态

核验日期：2026-10-09。**公开文档、申请入口、样例响应、离线测试和账号真实联调是不同阶段。** 当前不把可申请合作写成已经取得权限，也不把演示 key 或本地假数据写成正式供应商响应。

| 渠道 | 已核验的公开证据 | 对本项目的状态 |
| --- | --- | --- |
| 携程商旅 | 官方 AI 开放平台文章列出酒店、火车、机票推荐及信息查询，并链接到 MCP 申请入口；生态页介绍厂商伙伴开发者平台 | 可评估企业/生态合作申请；未核实个人开发者准入、具体测试凭据、价格和最终工具权限，尚未接通 |
| 铁路 12306 | 官方网站提供旅客车票与常用信息查询 | 未查到普通开发者可自助注册、申请 key 的官方公开查询 API 文档；不得据此断言不存在任何定向企业合作接口，也不能把网页请求端点当成获得正式 API 服务权限 |
| 飞猪 FlyAI | 官方快速入门要求在控制台取得正式 API Key；FAQ 说明部分价格缺失需进入详情查询 | 本轮无 key 体验 CLI 已返回航班、火车和酒店候选，但价格可能掩码、缺币种或缺失，库存不能据此保证；正式 key 尚未取得，获得 key 也不等于所有房价自动完整 |
| 聚合数据 ID817 | 有具体铁路查询端点、参数、票价和余票字段及申请/认证/测试流程 | 本地只读适配器与离线测试已完成，缺少 key，未真实联调；不是 12306 官方开放 API |
| 极速数据铁路 | 官方产品页提供车次、时刻、票价、余票查询和试用套餐 | 备用候选，文档核验完成，尚未实现本项目铁路适配器或取得调用权限 |
| 极速数据长途汽车 | 官方产品页提供城际参考时刻、票价查询和试用套餐 | 本地适配器与离线测试已完成；不支持指定日期/实时库存，缺少 key，未真实联调 |
