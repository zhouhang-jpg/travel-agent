## 实际请求契约

只读端点为 `GET https://apis.juhe.cn/fapigw/train/query`，不调用订票、支付或取消接口。

| 参数 | 当前实现 |
| --- | --- |
| `key` | 由后端注入产品专用凭据 |
| `search_type` | `1` 表示站名；`2` 表示站码 |
| `departure_station` / `arrival_station` | 用户/模型提供的站名原样发送，或使用已核实的聚合站码 |
| `date` | 明确的出行日期，`YYYY-MM-DD` |
| `enable_booking` | 固定为 `2`，请求所有班次，避免把未可预订的班次过滤掉 |

站名查询不会将“北京”擅自替换成“北京南”，也不能据此宣称检索了城市内所有车站。结果使用供应商实际返回的站名与站码。使用站码时，输入需形如 `juhe_train:VNP`；两端必须同时使用站码，并验证结果与请求站码一致。高德地点 ID 不可直接作为铁路站码。

供应商文档限制仅查询 15 天内日期。适配器按中国标准时间检查**今天至未来第 14 天，共 15 个日期**；此范围之外返回 `unsupported_date`，不猜测远期班次。当前只处理现代中国大陆售票窗口，以 UTC+08:00、时区名称 `Asia/Shanghai` 计算，不进行历史时区换算。

首版限制单名标准成人、无儿童、人民币；多人数、儿童和其他币种返回明确的能力错误，不按人数盲目乘票价。`train_types` 和 `seat_class` 在结果上过滤，席别支持供应商返回的准确名称或席别码。`max_results` 按席别报价数量截断，并明确标记结果未完整返回。

## 价格、库存和时刻语义

- 每个席别生成一条报价，已知正金额标为 `query_quote`、`CNY`、`per_person`、`priced_persons=1`；对应一名标准成人单程票面价格。
- 税费和服务费是否包含保持 `unknown`，没有伪造整段旅行费用或锁价期限。零值、空值和缺失价格保持未知，不推断免费。
- “有”表示供应商查询时显示可用，但无精确张数；“无”与零表示不可用；正整数保留剩余张数；“--”、缺失值和未识别状态保持未知。
- 上述库存不是锁座、预订或支付成功的证据。
- 到达日期由请求日期、实际发车钟点及供应商历时共同计算，同时核对供应商到达钟点，可处理跨日和超过 24 小时的运行时间。缺失历时时不根据钟点猜测到达日期；不一致则返回上游数据错误。
- `complete` 表示本次适配结果是否因缺失关键数据或截断而不完整；即使为 `true`，也不代表包含全城所有车站、全量费用或取得预订保证。

所有业务错误通过 `ToolFailure` 返回。上游错误不能伪装成成功的空列表；错误消息只使用安全的错误类别和数值码，不转发可能含 key 的上游正文。来源引用使用产品文档链接，不包含带凭据的请求 URL。
