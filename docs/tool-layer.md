# 工具层设计（初版可执行契约）

本文记录工具层契约，不把可调整默认值视为已经确认的产品要求。上层 `travel_agent` 已用轻量 ReAct 自主决定提问与工具组合，不固定业务步骤；本层负责只读查询与校验，不保存跨会话偏好。完整 Agent 行为见 `agent-behavior.md`。

## 分层与调用

`schemas/` 定义输入输出；`providers/` 封装独立数据服务；`webpage.py` 和 `itinerary.py` 提供通用工具；`registry.py` 负责注册、校验、限额、调度及模型 JSON Schema；`bootstrap.py` 注入配置和 HTTP 客户端；`api.py` 提供本地 FastAPI 接口。供应商接受可注入 `httpx.AsyncClient`，因此协议映射可以脱离真实凭据测试。

统一异步调用：`registry.dispatch(name, arguments, call_id=...)`。正常工具结果与工具执行错误都返回 `ToolResult`，业务错误 HTTP 状态为 200，调用方必须检查 `status`；非法 HTTP 请求包返回 422，过大请求返回 413，请求体接收超时返回 408。模型工具调用 ID 可原样关联，未提供则生成 UUID。

结果包含 `schema_version`、`tool_name`、`call_id`、`status`、`started_at/finished_at`、`data/error`、`content_trust`。`data` 必须再次通过工具声明的输出类型校验；错误包含 `code/message/retryable`，不含 HTTP 请求、密钥、供应商原始错误或堆栈。没有默认自动重试，以免隐藏额度消耗。

所有数据模型禁止未知字段，并拒绝非有限数值；字段按各自语义校验，不开启对所有类型的统一 strict mode，以支持 JSON 字符串日期和 Decimal。`Source` 保存 provider、URL、UTC 查询时间、可空的数据时间与归因。数据时间缺失保持 null，不能把查询时间伪造为发布/更新时间。坐标包含经纬度和显式 CRS，不默认转换。外部文本是证据数据，不能成为系统指令。

模型定义采用常见 `type:function` 与 `function{name,description,parameters}` 形式，保留标准 JSON Schema `$defs` 引用；DeepSeek Flash 已通过实际多轮工具调用验证，其他厂商及 strict-mode 子集仍需独立兼容性验证。

## 可用性与上下文边界

| 状态 | 意义 | 默认模型定义 |
| --- | --- | --- |
| ready | 有实现，必要配置存在；可开始调度 | 导出 |
| not_configured | 有实现，必要密钥/Host 缺失或 Host 不合规 | 不导出 |
| not_implemented | 只有契约/接口，没有供应商实现 | 不导出 |

`ready` **不是**真实鉴权、服务权限、额度或数据正确性的证明。配置密钥后仍可能得到鉴权/限流/响应错误。目录的 `live_verification=not_recorded` 表示进程没有载入验证记录；真实联调证据单独保存在脚本报告和验证文档中，不能随配置自动改为 passed。

无配置时导出网页抓取、行程校验和开放时间证据查询（需提供可读网页）；配置高德、和风、博查后导出8项基础工具。全部12项契约可导出。`quote_registry.py`接入独立浏览器12306/出行365/东航，以及FlyAI/聚合/极速；未配置则不返回成功空结果。FlyAI需要已有Node/CLI及Key或明确体验开关；浏览器需要显式启用并安装Chromium。铁路默认12306，仅配置的受阻降级会切换且返回来源/原因；显式来源、未开售和空结果不切换。普通大巴已导出，机场巴士和高铁接驳暂缓。详见`providers/browser-tickets.md`。

调度默认最多 4 个并发，总执行时限 20 秒（包括排队），输入最多 256 KiB，序列化结果最多 2 MiB。供应商单请求另有 15 秒和 2 MiB 响应限制。这些是可调整的工具资源默认值，不是已定的 ReAct 总轮数/成本/上下文阈值。超限返回明确错误，不静默裁剪历史。网页正文有独立显式 `truncated` 字段。

上层运行器已保存原始用户输入、完整模型消息（含供应商要求回传字段）、完整工具调用及本层结果，使用 SQLAlchemy 持久化。历史不摘要、裁剪或检索替换；应用层无上下文或模型输出长度限制，其他执行资源超限时明确结束并保留历史。公开 API 与 SSE 不展示隐藏推理和原始工具结果。

## 工具目录

| 工具 | 输入重点 | 输出与限制 |
| --- | --- | --- |
| search_places | 文本/分类、区域或 GCJ-02 周边、分页 | POI、可空坐标与原始营业描述；不是完整候选集 |
| get_place_details | 一个高德 POI ID | found 与详情；合法未找到和供应商错误分开 |
| get_attraction_opening_hours | 名称、可选城市/POI ID/参观日期/建议官网 URL | 地图常规营业原文、日期公告搜索及网页证据、身份候选、失败和未确认状态；见 opening-hours.md |
| get_routes | GCJ-02 起终点、模式；公交城市编码及可选出发时间 | 米/秒、路线步骤、参考费用；不是票价/库存 |
| get_weather | 显式CRS/区域；daily/hourly/alerts/indices模式；带时区目标时刻/时段或日期 | 实际日/小时预报、当前预警/每日指数、数值单位与归因；时间匹配/部分/缺口/超覆盖明确区分，不外推或插值 |
| search_web | 关键词、时间范围、结果数 | 来源链接、摘要、可空发布时间及原文日期；不可信外部内容 |
| fetch_webpage | URL、最大正文字符数 | 公共 HTML/文本、来源、最终 URL、截断标记 |
| validate_itinerary | 行程及证据、明确的固定安排/住宿/费用覆盖范围 | 各项检查与 valid/invalid/unknown；仅验证一致性 |
| search_flights | 起终点、日期、旅客、舱位 | FlyAI 候选查询；价格口径和库存未核验，响应不完整 |
| search_trains | 起终点、日期、旅客、车种/席别 | 聚合票价/余票字段，或显式 FlyAI 候选查询；按供应商返回保留未知 |
| search_coaches | 起终点、日期、旅客、车站 | 极速参考班次/票价；不支持日期查询，不能确认当天发车或余票 |
| search_hotels | 目的地、入住/离店、人数年龄、房间数 | FlyAI 候选酒店；房型、准确房费与库存未核验，拒绝不支持的多人条件 |

具体必填字段、枚举与类型以 Pydantic 和导出的 Schema 为准。上述工具不是需求分类或固定执行顺序。地理编码尚未作为独立工具加入这 12 项，可后续按需求扩展。

## 网页读取安全边界

仅接受默认端口的 HTTP/HTTPS，拒绝 URL 凭据、控制字符、反斜线、IPv6 scope、localhost/内部域名；解析全部 DNS 结果，任一非公网地址均拒绝。拒绝本机、私网、链路本地、组播、保留地址及常见 IPv6 转换/隧道地址。请求连接到已验证的数字 IP，同时保留原域名 Host/TLS SNI；不发生“验证一次、连接时再次解析”的 DNS 重绑定窗口，TLS 证书验证保持开启。

禁用环境代理、跨请求 Cookie 和自动重定向；每个跳转重新校验，最多 3 跳，禁止 HTTPS 降为 HTTP。15 秒总时限包含 DNS 和解析阶段；网络分段超时也受限制。只接受 200 的 HTML/XHTML/纯文本，1 MiB 正文上限，要求 identity 编码并拒绝压缩响应，避免解压膨胀。使用标准库增量 HTMLParser，每 8 KiB 设置取消检查点，限制嵌套深度、节点数及未闭合 token 缓冲区；标题上限 512 字符，单独返回 title_truncated。跳过脚本、样式和常见隐藏节点，不运行 JavaScript；需要 JS、登录、PDF、异常复杂 HTML 或压缩-only 的网页会受限，不能宣称完整浏览器兼容。

上述校验不判断网页事实准确性或执行其中的指令。读取结果标为不可信数据。服务目前是本地开发工具；公网部署需要独立身份认证、授权和运维边界设计。

## 供应商接入验收

供应商文档依据见 `docs/providers/`，其中记录本次核对日期及接口限制。真实账号验收应核实请求方向、服务权限、响应形状、配额、费用口径与数据有效期。票务酒店需要确认是本 Agent 调用供应商的客户搜索接口；商户推送库存/报价、订单通知或供给回调不能当作客户查询 API。当前 FlyAI、聚合、极速实现均用于只读搜索；其配置可用性与真实字段验收分别记录。
