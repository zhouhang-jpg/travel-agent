## 保存与修改

`save_itinerary`是当前会话内部工具，不暴露为无归属的供应商HTTP调用。
首份方案使用`document`，继承既有`ValidateItineraryInput`；复用活动/交通、住宿、固定安排、
费用、source_catalog/source_ids与同一校验器，不另造平行行程模型。
补充party、requirements、protection和证据适用条件，作为当前会话的最小索引。

局部修改优先使用`base_version_id + patch`：items/lodging/costs/requirements按稳定id合并
指定字段，字典递归合并、数组替换；未涉及内容由服务保留。首次必须提供完整候选，
也可基于当前版本提供完整document；只能二选一。删除显式列在remove_*。
set_fields只接受合同列出的字段。合并后完整Pydantic验证、锁定检查与行程校验均照常执行。

每个工具效果对应稳定版本ID。草案与原始工具结果在同一租约围栏事务提交。
等待用户或运行失败不发布草案；同轮后续保存失败会撤销该轮已有草案，避免误发旧候选。
成功最终答复时，在提交业务结果的同一事务中发布该轮最新草案并更新current指针。
已发布版本保持不变，可查看旧版本；恢复不重复发布或增加版本号。

普通查询/探索建议无需保存完整行程。LLM决定查询、澄清、修改范围及交付，协议不指定
天气→交通→酒店等步骤，不强制每轮校验或每轮提问。保存本身复用校验器，无需为保存
机械重复调用validate_itinerary。当前已用/剩余模型请求和主动时间提供给模型，预算仍12/300。

## 条件、锁定与用户信息

requirements区分user、assumption、evidence；仍有效的用户条件须保留，修订/替代使用
更新的用户消息依据。user_message_references仅提供完整历史中用户消息的序号和稳定ID，
不重复复制正文，不压缩或替代原始历史，也不跨会话注入偏好。

protection区分明确locked和user_reported_booked。必须引用真实用户消息ID及逐字原话；
模型生成的普通安排默认不锁定。保护项被改变、删掉或清除保护时，工具拒绝候选，当前
版本保持不动；release_protections须引用在当前版本之后接受的用户授权。
旧版本缺少后加可选字段时规范化后比较，避免JSON默认值升级误判为修改锁定项。
用户自报已订只代表用户信息，UI明确“你告知已预订 · 未核验”，不会调用取消/下单接口。

任意自然语言条件或解除授权的**语义理解仍由LLM负责**。服务验证引用存在、逐字一致、
时序及已保存保护项完整性，不能独立证明任意一句话足以授权所有修改。
局部“你决定”不扩大到其他条件，冲突由LLM解释并澄清；行为评测单独检查这个边界。

## 证据、交通与费用

available_sources给出从完整原始工具结果提取的真实来源ID与查询条件；保存可使用
available_source_ids导入，Source的provider/URL/原始查询时间由服务复制，降低手工抄写错误。
完整工具JSON及供应商附加字段仍保持原样。public API不会输出query_conditions原始参数。

来源须能对应本会话实际成功查询。来源声明缺失/不匹配、查询条件变化、目标日期/人数/房间
不符、旧来源适用条件被改写或关联安排变化均标待复核，原取数时间不更新为“现在”。
动态证据是查询时快照，不提供统一虚构TTL；原始PriceEvidence有效期已过时不能当新报价。
用户信息与假设分别显示记录/参考时间；未匹配来源显示声明时间未核实。

转场可列进站、安检、换乘、入园、用餐/休息等buffers，区分queried、estimate、unknown。
估计须有解释，unknown分钟为null。不足以容纳已提供行驶+缓冲的空隙会冲突；估计满足
不升级成实查通过。交通块自身可使用travel_duration，不能只看它与邻项的空隙。
实查来源导入后，对应路线duration_s给出最短已查时长下界；不能声明更短时长让交通块通过。
酒店入住日期使用lodging，不能将整个入住区间错误表示为必须全程停留的固定时间块。

费用total仍是全体出行人数、适用房间和全部晚数的归一化金额，basis记录计算口径。
查询报价须与原始PriceEvidence金额、币种、计价单位及查询人数/房间相符；支持明确
per_person/per_room_per_night等口径换算，未知口径或多人范围不符仅作参考。
税费以原始报价保留，未知不补成已含。未知费用为null，不按零计；已知/参考小计按币种
分别汇总，变化也是小计差值，缺币种的一侧不臆设零，不做自动汇率转换。

保存拒绝已知时间重叠/固定安排/住宿等冲突，但允许有明确复核项的unknown方案交付。
来源相符仅证明它来自该次查询，不证明上游事实真实、未来可售、用户需求完整覆盖或安全。
LLM生成的说明文本与外部证据语义仍需评测；本轮不是“所有行程已完全核验”的保证。

## API、展示及数据库

- GET `/conversations/{id}`附带当前已发布itinerary。
- GET `/conversations/{id}/itineraries`列出已发布版本与current_id。
- GET `/conversations/{id}/itineraries/{version_id}`查看该会话的一个版本，不能跨会话读取。
- 发布生成持久`itinerary_updated`事件；网页取得同一保存版本，显示活动、交通、住宿、
  费用口径、锁定状态、修改原因、前后差异、已知小计变化及待复核项。可只读切换旧版。
